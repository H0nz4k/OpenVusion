# WaterFall 0.4.1 / OpenVusion RF Probe 0.7.1 — release candidate

Datum: 2026-08-12

Tento checkpoint dokumentuje uzavřený release candidate vzniklý po release 0.4.0 / 0.7.0.

## WaterFall 0.4.1

Doplněno:

- SQLite Capture Center a detail/filter událostí;
- live RF sweep + RF region inference + WATCH burst timeline;
- persistentní katalog pozorovaných identifikátorů/zařízení;
- BLE observer s ručním START/STOP a explicitním active/passive režimem;
- volitelný skutečný 802.11 monitor-mode observer;
- PCAP/PCAPNG/.cap Inspector přes tshark, Wireshark display filter, frame detail a hex dump;
- JSONL export a SQLite snapshot;
- RF STEP / RSSIMODE ovládání pro firmware 0.7.1.

Mock acceptance v build prostředí: PASS (HTTP server, capture start/stop, SQLite, RF regiony, RF_BURST, filtry, 25-event JSONL export). Reálný BLE/tshark/802.11/TWN4/GPIO souběh vyžaduje ověření na Raspberry Pi.

## OpenVusion RF Probe 0.7.1

Doplněno:

- RX-only `WATCH START MHz threshold sample_us`;
- `BURST` stream s peak/avg RSSI, délkou a počtem vzorků;
- `STEP 1|2|5|10`;
- `RSSIMODE LAST|MAX|AVG`;
- každý použitý RSSI sample čeká na vlastní `EVENTS_RSSIEND` před čtením `RSSISAMPLE`;
- WATCH se ukončuje při ztrátě USB DTR;
- statická kontrola potvrzuje RXEN a absenci radio TX-enable tasku.

0.7.1 v tomto prostředí neprošel fyzickým NCS build/flash testem. Poslední fyzicky ověřený firmware zůstává 0.6.1. Před flashem 0.7.1 je závazný clean NCS 3.4.0 build + `verify_build.py`, následně `test_usb.py` na Raspberry.
