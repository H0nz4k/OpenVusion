# Field Workflow

1. Power on the device.
2. Wait until screen shows **READY** / **READER READY**.
3. Tap **START**.
4. Present a VUSION tag to the reader.
5. Wait for **CAPTURE OK** (green).
6. Remove the tag when prompted.
7. Present the next tag.
8. Tap **STOP** when finished (finishes in-flight capture first).
9. Optionally tap **SHUTDOWN** and confirm.
10. Export with `/opt/Sniff/scripts/export-data.sh /media/usb`.

Read-only only — never write to tags.
